# CodeAlpha - CGPA Calculator (C++ Project)

## 📖 Project Description
This is a simple CGPA Calculator developed in **C++**. The program allows users to enter their subjects, marks/grades, and credit hours to calculate their CGPA accurately.

This project was developed as part of the **CodeAlpha Internship Program**.

---

## ✨ Features
- Input multiple subjects  
- Enter marks or grade points  
- Credit hour-based calculation  
- CGPA calculation logic  
- Simple console-based interface  
- Accurate result output  

---

## 🧮 Working Logic
The CGPA is calculated using the formula:

CGPA = (Total Grade Points × Credit Hours) / Total Credit Hours

Each subject’s grade points are multiplied by its credit hours, and the final CGPA is computed.

---

## 🛠️ Technologies Used
- C++ Programming Language  
- Console Application  

---

## 🚀 How to Run Project
1. Open project in any C++ compiler (Dev C++, CodeBlocks, or Visual Studio)  
2. Compile the file  
3. Run the program  
4. Enter subject details when prompted  
5. View calculated CGPA
